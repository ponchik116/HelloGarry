GARRY'S NEIGHBOR v1.0.0
Hello Neighbor + Garry's Mod style sandbox

ЧТО ДОБАВЛЯЕТ МОД
- 1 — создать Cube
- 2 — создать Sphere
- 3 — создать Cylinder
- F2 — взять/отпустить ближайший созданный проп
- I/J/K/L — двигать проп
- U/O — двигать вверх/вниз
- Q/E — вращать
- F3 — удалить ближайший проп
- F4 — удалить все созданные пропы
- F1 — включить/выключить sandbox
- H — показать управление

ТРЕБОВАНИЯ
- Hello Neighbor в Steam (AppID 521890)
- UE4SS / RE-UE4SS с поддержкой Lua

УСТАНОВКА
1. Не запускай игру во время установки.
2. Запусти install.bat.
3. Скрипт сам ищет библиотеку Steam и Hello Neighbor.
4. После установки запусти Hello Neighbor, зайди в игровой уровень и нажми H.

UE4SS
Пакет содержит только файлы самого мода и установщик. Файлы Hello Neighbor не распространяются.
Официальный RE-UE4SS: https://github.com/UE4SS-RE/RE-UE4SS/releases
Актуальная документация по установке: https://docs.ue4ss.com/installation-guide

ВАЖНО
Это готовый исходный Lua-мод для UE4SS, но в этой среде нет установленной копии Windows Hello Neighbor, поэтому честно отметить реальный runtime-тест нельзя.
Мод работает как single-player sandbox layer внутри Hello Neighbor; Garry's Mod здесь является источником игровых механик, а не требуемой для запуска игрой.

УДАЛЕНИЕ
Запусти uninstall.bat.
