GARRY'S NEIGHBOR — Hello Neighbor + Garry's Mod style sandbox

What this is:
A real UE4SS Lua mod for Hello Neighbor. It adds a small Garry's Mod-style sandbox layer:
- spawn a cube, sphere or cylinder using the engine's BasicShapes;
- grab/release the nearest spawned prop;
- move and rotate the grabbed prop;
- delete one prop or clear all props;
- toggle the sandbox on/off.

Controls:
1 Cube
2 Sphere
3 Cylinder
F1 Sandbox on/off
F2 Grab/Release nearest spawned prop
I/J/K/L Move
U/O Up/Down
Q/E Rotate
F3 Delete nearest spawned prop
F4 Delete all
H Help

Install:
1. Keep this package next to the game.
2. Run install.bat.
3. The installer finds Steam's Hello Neighbor (AppID 521890) and places the UE4SS mod in its Binaries\\Win64\\ue4ss\\Mods folder.
4. Start Hello Neighbor, enter a playable level, press H.

Important:
- This package contains no Hello Neighbor or Garry's Mod game files or assets.
- It requires UE4SS Lua support. The installer does not bundle UE4SS binaries.
- This is a first playable slice, not a full Garry's Mod replacement.
- The current environment could not launch the user's installed Windows game, so the package is NOT claimed as runtime-tested here.
- Garry's Mod is represented by reimplemented sandbox mechanics; no Valve game assets are redistributed.
